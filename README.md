# EchoLedger

EchoLedger utilizes distributed ledger technology to process real-time cryptocurrency transactions via a scalable blockchain manager platform.

The key benefits of using EchoLedger include:

- EchoLedger utilizes distributed ledger technology
- to process real-time cryptocurrency transactions
- via a scalable blockchain manager

## Technology Stack

- python
- Modular architecture

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EchoLedger.git`
2. `cd EchoLedger`
3. Install in editable mode: `pip install -e .`

## Configuration

EchoLedger is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
